# 体内成熟卵和体外成熟卵结合技术在不孕症治疗中的临床应用及其安全性研究新闻稿

> 更新时间：2026-09-17 (UTC+8)

喜讯：我院生殖医学科李友筑团队参与申报项目获2023年度妇幼健康科学技术奖三等奖！

近期，2023年度妇幼健康科学技术奖名单正式揭晓。由我院生殖医学科李友筑教授团队牵头，联合解放军总医院第七医学中心、同济大学附属第十人民医院优秀研究团队共同申报的科研项目——“体内成熟卵和体外成熟卵结合技术在不孕症治疗中的临床应用及其安全性研究”，经过严格评审，喜获三等奖！

项目简介

全世界约10%-15%的夫妇面临不育症困扰，传统控制性超促排卵辅助生殖技术虽解决了药物治疗的局限性，但存在成本高、多胎妊娠及卵巢过度刺激综合征（OHSS）等并发症。自然周期IVF技术因避免OHSS、费用低等优势重新获得认可，但其周期取消率高的缺点促使未成熟卵母细胞体外成熟（IVM）技术发展，尤其为PCOS患者提供了安全方案。

卵泡波理论挑战传统单波卵泡理论，证实月经周期中可发生2-3次卵泡募集。基于此，李友筑团队研发自然周期IVF/M技术（优势卵泡IVF联合小卵泡IVM），并取得以下突破：

1. 技术规范优化:确立IVM及IVF/M的临床诊断指标、取卵时机与实验室操作流程，优化卵丘卵母细胞复合体(COCs)处理方式。

2. 适应症拓展:约50%不孕人群适用自然周期技术(36.8%适合 IF/M，15.4%适合IM)，对输卵管因素男性不育等各类不孕类型的临床妊娠率达30.4%-46.9%。

3. 疑难病例应用:为反复IF失败的卵巢低反应患者提供解决方案，证实小卵泡未成熟卵母细胞经体外成熟后可支持健康胎儿发育。

4. 安全性验证:分子生物学检测表明，体外成熟卵与体内成熟卵的表观遗传学、染色体数目无显著差异，胚胎非整倍体率不增加，且促排卵过程中儿-6蛋白分泌可能影响胚胎发育。

该技术兼具自然周期IVF与IVM的优势，避免OHSS，临床妊娠率与促排卵方案相当，且操作简便、费用低。目前已获1项国家实用新型专利，发表10篇论文（含9篇SCI，JCR一区5篇），他引107次，单篇最高46次，成果在战略支援部队特色医学中心等军内外医院推广，并通过 “生育关怀进军营” 等项目服务官兵，推动辅助生殖技术回归自然周期趋势。

此次荣获妇幼健康科学技术奖，是对李友筑教授团队及我院生殖医学科不懈创新和卓越贡献的充分肯定！我们表示热烈祝贺，并期待团队在未来取得更多突破性成果，造福更多不孕不育家庭！
